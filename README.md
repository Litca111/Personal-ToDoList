# 个人任务清单（网页版）

一个纯 Python 标准库实现、零第三方依赖的网页版个人任务清单。

## 功能

- ✅ 添加 / 编辑 / 删除任务
- ✅ 标记完成 / 未完成
- ✅ 优先级（高 / 中 / 低）
- ✅ 截止日期（自动识别「已逾期」）
- ✅ 分类（标签）与按分类筛选
- ✅ 备注
- ✅ 筛选视图：全部 / 进行中 / 已完成 / 已逾期
- ✅ 数据本地持久化（`tasks.json`）

## 运行

```bash
python app.py
```

然后浏览器打开 <http://127.0.0.1:8000>

（可通过环境变量 `PORT` 修改端口，默认 8000）

## 目录结构

```
ToDoList/
├── app.py            # 后端服务器（http.server + JSON 持久化）
├── tasks.json        # 任务数据（首次运行自动生成）
└── static/
    ├── index.html    # 页面结构
    ├── style.css     # 样式
    └── app.js        # 前端逻辑
```

## 接口

| 方法   | 路径              | 说明       |
| ------ | ----------------- | ---------- |
| GET    | `/api/tasks`      | 获取全部任务 |
| POST   | `/api/tasks`      | 新建任务   |
| PUT    | `/api/tasks/<id>` | 更新任务   |
| DELETE | `/api/tasks/<id>` | 删除任务   |
