# 个人任务清单（网页版）

一个纯 Python 标准库实现、零第三方依赖的网页版个人任务清单。

## 功能

- ✅ 添加 / 编辑 / 删除任务
- ✅ 标记完成 / 未完成
- ✅ 优先级（高 / 中 / 低）
- ✅ 截止日期（自动识别「已逾期」）
- ✅ 分类（标签）与按分类筛选
- ✅ 备注
- ✅ 筛选视图：全部 / 进行中 / 已完成 / 已逾期
- ✅ 勾选完成的任务在 **12 小时后自动删除**（显示删除倒计时）
- ✅ **每日任务**栏目：每天凌晨 4 点自动刷新完成状态，无需重复输入；完成即累计「已完成周期数」
- ✅ **每周任务**栏目：每周一凌晨自动刷新完成状态，无需重复输入；完成即累计「已完成周期数」
- ✅ 数据本地持久化（`tasks.json`）

## 每日 / 每周任务说明

- 添加任务时在「任务类型」下拉中选择 **每日任务** 或 **每周任务**，会进入对应栏目
- 每日 / 每周任务**永久保留**，不会被「12 小时自动删除」影响
- 刷新规则：
  - **每日任务**：每天凌晨 4 点自动刷新为「未完成」（03:59 前仍算前一天）
  - **每周任务**：每周一凌晨自动刷新为「未完成」
- 勾选完成 → 显示「今日/本周已完成」，并累计 `已完成 N 天/周`
- 取消勾选 → 回退本次累计；重复勾选不会重复累加

## 运行

### 方式一：VSCode 一键启动（推荐）

1. 用 VSCode 打开本文件夹
2. 确保已安装 **Python 扩展**（ms-python.python），并在右下角选择 Python 解释器
3. 打开 `app.py`，按 **`F5`**（或「运行 → 启动调试」）
4. 终端显示 `访问地址: http://127.0.0.1:8000` 后，浏览器打开该地址

### 方式二：命令行

```bash
python app.py
```

然后浏览器打开 <http://127.0.0.1:8000>

（可通过环境变量 `PORT` 修改端口，默认 8000）

## 目录结构

```

├── app.py            # 后端服务器（http.server + JSON 持久化 + 自动清理）

├── .vscode/

└── static/
    ├── index.html    # 页面结构

```

## 接口

| 方法   | 路径              | 说明       |
| ------ | ----------------- | ---------- |
| GET    | `/api/tasks`      | 获取全部任务 |
| POST   | `/api/tasks`      | 新建任务   |
| PUT    | `/api/tasks/<id>` | 更新任务   |
| DELETE | `/api/tasks/<id>` | 删除任务   |
